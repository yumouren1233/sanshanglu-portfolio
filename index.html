Project 01

智能戒指

Smart Ring — 智能穿戴设备外形优化设计

已量产
工业设计3D建模CMF设计智能穿戴

项目背景

客户需要一款兼顾舒适性、轻便性和高端质感的智能穿戴戒指。原有方案在佩戴体验和外观细节上存在明显的优化空间，需要在不改变内部电子元件布局的前提下，重新定义产品的外形语言。

核心设计挑战

在极小的体积内平衡电子元件空间与人体工学佩戴舒适度，同时将产品重量控制在目标范围内。戒指需要长时间佩戴无感，但又要保持高端产品应有的质感与分量感。

设计过程

我的角色是在上级审核通过后，独立完成外形优化设计的全流程。从用户佩戴场景分析出发，结合竞品形态对比，输出3版外观方案草图，经过方案评审后确定最终方向，再进行精细化3D建模和CMF定义。

落地成果

完成量产级3D模型交付，配合结构工程师完成开模对接。产品以舒适轻便的佩戴体验获得客户认可，实现了智能功能与高端质感的统一。

Project 02

四羊方尊

国宝级青铜器的当代文创转化

已量产
工业设计3D扫描建模榫卯工艺文创产品

项目背景

将国宝级青铜器"四羊方尊"转化为面向大众消费市场的文创产品。核心命题是在保留文物高辨识度的同时，实现现代化表达和量产可行性——让博物馆里的"文物"成为日常生活中的文化消费品。

核心设计挑战

原始文物纹样极其复杂，直接3D打印或注塑无法还原细节。需要在保留文化辨识度的前提下，对结构和纹样进行系统性简化，以适应量产工艺的限制。同时，产品需要分件生产后组装，结构拆分方案直接影响装配效率和成品品质。

设计过程

我负责扫描件建模、布线优化、构件切割分配和榫卯拼接工艺设计。由于生产难度大，纹样和结构经历了多轮修改。

01 文物3D扫描→ 02 点云数据处理→ 03 结构分件方案→ 04 榫卯结构开发→ 05 纹样简化→ 06 打样验证→ 07 量产上市
文物原型参考

产品白模拼接过程
白模拼装组件
结构分件清单
纹样简化线稿版

落地成果

成功量产上市，实现了"让文物走进日常"的设计目标。产品在保留四羊方尊核心文化辨识度的同时，以现代化的结构方案和工艺标准，完成了从博物馆藏品到消费级文创的完整转化。

Project 05

智能头盔

轻量化低风阻智能头盔概念设计

概念阶段
工业设计3D建模渲染概念设计

项目背景

客户需要一款同时满足轻量化、极致低风阻和设计感的智能头盔产品。在上级审核通过后，我负责外形设计延伸工作。

核心设计挑战

轻量化与低风阻往往要求流线型简洁外形，但客户同时要求保持辨识度和设计感。需要在空气动力学效率与视觉吸引力之间找到平衡。

设计过程

从概念草图出发，探索多种头盔形态方向——从开放式到全包覆式，再到一体化气动骑行头盔。经过方案筛选后确定最终设计方向，进行3D建模、材质定义与渲染输出。
